The Noticeboard holds up to five Daily Challenges at once. One new challenge arrives each review day, and when a sixth would arrive the oldest one falls off the list.

## Working a challenge

Challenges make progress from ordinary reviews. Mining copper, cooking chicken or killing an enemy above the named combat level all count toward a matching challenge without any separate action.

One challenge can be pinned at a time. Pinning does not change how it progresses; it marks the task you are working on.

## Handing in

A finished challenge is handed to the Quartermaster. Some challenges want the items you made turned in; if you no longer hold them the hand-in is refused and names what is short, so you can obtain them and come back.

A challenge that falls off the end of the list pays nothing, even when it was finished. Hand a finished challenge in before it is displaced.

## Rewards

Every completed challenge pays bonus experience. A hand-in also pays a Challenge Mystery Bag, which opens for the exchange value of the items turned in. A combat challenge pays a Challenge XP Lamp instead, and you choose which combat skill its experience lands in.

## Blocking a skill

The Quartermaster will stop setting challenges in a skill you have maxed. This is per skill, not a switch that turns the system off.
