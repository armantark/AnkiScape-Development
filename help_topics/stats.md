Stats shows your current levels and experience across complete and Combat-trained skills.

## Reading progress

Skill experience uses the shared RuneScape level table. Source action XP is stored separately from AnkiScape pacing, so changing the review-action multiplier changes the number of action attempts rather than rewriting each action's base XP.

Combat-trained stats advance through the selected attack style and encounter. Management-only systems can appear elsewhere without pretending to be directly trained skills.

Use [Skills](help:skills) to change the foreground action or [Achievements](help:achievements) for milestone progress.
