Automation changes how AnkiScape chooses among options you already own. It does not create resources, ignore unlocks, or turn a blocked target into a runnable one.

## Casual

Casual mode chooses sensible owned supplies and beneficial equipment, keeps common loops moving, and uses safe defaults when a choice can be made without changing the activity's identity.

## Advanced

Advanced mode preserves target-local quantities, exact selections, and policy choices. If an exact resource runs out, the policy can remain visibly lapsed rather than silently substituting something else.

## Shared boundaries

Automatic refills and replacements happen only at the settled action or Bank boundary. A detour replaces that review's ordinary target action; it does not award both outcomes.
