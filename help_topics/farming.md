Farming is managed through patches and a review-driven queue rather than one permanent training target.

## Planning a run

Choose the crop and optional care for each patch, then add those actions to the queue. User-defined presets can fill a plan without planting anything immediately. Queue order remains explicit.

## Running the queue

Eligible reviews perform queued Farming work. A full run follows the same queue model; it does not use elapsed wall-clock time. Growth, disease, protection, watering, and harvest state stay attached to the patch.

**Dig up** and other direct management actions are deliberate player commands. They never masquerade as review undo.
