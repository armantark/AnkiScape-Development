Settings controls presentation, review pacing, and developer diagnostics. It does not change historical source values.

## Interface

Floating-widget position, HUD visibility, notifications, and related display choices affect how progress is shown. Light and dark colors follow Anki's active palette.

## Review pacing

The review-action multiplier repeats complete action attempts inside one eligible review. Requirements, failures, resource use, outputs, cadence, and undo still apply to each attempt; the whole review remains one atomic transaction.

## Developer tools

Developer mode exposes diagnostics and otherwise hidden validation surfaces. It can make broken Help topic references fail visibly, but it does not unlock gameplay content or alter save rules.
