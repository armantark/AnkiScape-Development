What Changed

  • tools/build_pre_eoc_quest_catalog.py generates and caches the source-backed catalog.
  • quest_catalog_generated.py stores the 185-row cutoff snapshot with oldids, requirements, QP, XP, and release order.
  • quest_data.py imports generated rows and overlays bespoke Rune Mysteries-style definitions for unlock-critical quests.
  • ui.py uses generated release-order metadata, so same-date quests sort by real game order.

Behavior Guarantees

  • Missing or incomplete prerequisite quests block start.
  • Unimplemented required skills block start as “not implemented.”
  • Generated XP for unimplemented skills parks in pending_skill_exp_rewards.
  • Completed quest bodies stay collapsed, keeping the full quest list manageable.
