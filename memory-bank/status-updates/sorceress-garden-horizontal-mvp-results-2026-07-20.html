What changed beyond the activity

Activities stopped feeling crowded

The picker now shows one semantic category per page. Previous/next navigation preserves the selected activity, height is measured from live rows, and the tree has no internal scroll window or false disclosure arrow.

Inventory is real

All four fruits and juices are registered, persisted, undoable, asset-backed items. Drinking returns a Beer glass. Dungeoneering herbs are deliberately absent.

Undo is atomic

A review trip, output, Farming XP, Osman Thieving XP, telemetry, and Garden state restore together. Introduction uses direct-action undo; preference changes remain ordinary settings.

UI taste was independently checked

Kimi K3 and Fable reviewed both the Garden card and pager. Confirmed issues in hierarchy, selection restoration, clipping, disclosure, copy, progress legibility, and accessibility were fixed.
