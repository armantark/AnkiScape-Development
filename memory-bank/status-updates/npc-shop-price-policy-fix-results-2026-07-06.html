No prices, lock reasons, or stock policy were invented in the frontend.

What changed

ROOT FIX · PRICE PIPELINE

Darkan cache prices, extracted once at generation time

A new Java helper opens the Darkan cache exactly the way the live server does and dumps the three inputs Shop.java uses: item value, item sell price, and the coin/Tokkul enum overrides. The generator joins those into the runtime catalog so every coin row carries real buy_price/sell_price plus a price_policy/price_source audit trail.

PRICE SEMANTICS · MIRRORS SHOP.JAVA

Custom prices override buys only

Where a shop JSON declares a custom price, it overrides the buy price only. Otherwise the buy price comes from ItemDefinitions.value plus the coin enum override, and the sell price from ItemDefinitions.sellPrice plus the sell enum override — the same branch structure as the Darkan server. Nothing is estimated or interpolated.
