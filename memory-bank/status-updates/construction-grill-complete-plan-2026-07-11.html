Settled decisions

Hybrid house model OWNER

Training is flat XP build targets from the full HouseObjects table (one build per review, materials consumed). A persistent house sheet tracks the durable state: rooms bought (coins + level per the HouseRooms ladder), servant hired, altar/burner status. Build targets gate on their room; rooms are the coin sink, builds are the XP.

HouseObjects.ktHouseRooms.kt

Servants = batch boost OWNER

Hiring a servant raises the per-review build batch for material-consuming builds, tiered by the Darkan ladder — Rick 375c/20, Maid 750c/25, Cook 2,250c/30, Butler 3,750c/40, Demon butler 7,500c/50 — using the sanctioned batching-per-review device. Wages per stint; no trip simulation invented.

HouseServants.kt

Owned gilded altar OWNER

Closes the Prayer grill's deferral: with Chapel + gilded altar + burners built, Prayer's hosted-altar flow gains an owned variant with no 1–10 finding roll. Burners consume one clean marrentill each per stint (+50% Prayer XP per lit burner; 350% total). Any-herb lighting is post-EOC RS3 — excluded.

Flatpacks as wiki gap-fill OWNER

Darkan never implemented flatpack crafting, so the pack list comes from a pre-EOC pin at build time. Workbench-tier gating per the HouseBuilds ladder; same XP as the normal build; tradeable, sellable output items.

HouseBuilds.kt:368+pin needed

House sheet: a section, not a tab OWNER

The sheet lives inside the Construction skill tab — a summary strip above the normal target list, expandable to the room view. No new top-level tab, and no function panel: it is a room inventory. Functions with no AnkiScape analog never surface on it.
