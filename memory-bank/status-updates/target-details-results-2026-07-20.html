What shipped

  • Collapsed-by-default Details for flat and grouped skill targets.
  • Live chance, output/damage, XP, requirements, modifiers, and blockers.
  • Locked-row inspection without selecting or starting that target.
  • Same-skill persistence with clean resets across skill, category, and Farming navigation.
  • A bounded scroll sheet so long Combat mechanics cannot crush the target list.

What stays hidden

  • Source files and audit labels
  • Equations and RNG state
  • Internal ticks
  • Fabricated precision

Fresh-eyes correction pass

Review found

  • Dense Combat text could consume nearly the whole target list.
  • Locked blockers were present in data but unreachable through clicks.
  • Direct Farming navigation could inherit an empty open panel.
  • Integer XP appeared as player-facing values such as 60.0.

Final behavior

  • Combat Details scroll within a 190-pixel body.
  • Locked rows explain themselves while gameplay callbacks stay inert.
  • Farming owns its existing patch-specific Details sheet cleanly.
  • Integer XP renders naturally as 60.

Only remaining gate

Fable’s required taste pass could not be invoked because the mandatory fresh quota probe cannot read Claude Code OAuth from macOS Keychain (security exit 51). Stale quota data was not used and the guard was not bypassed. This is an external QA/auth gate, not an unresolved product-design decision.
