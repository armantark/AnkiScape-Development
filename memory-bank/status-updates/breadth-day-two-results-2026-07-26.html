Why a fourth verification pass was worth running

Three passes found nothing

Each family reported all nine breadth criteria passing. Three separate verification passes — all Claude models — cleared them.

They read the code and re-confirmed the author's reasoning. That is the failure: the author writes the code and its tests in one pass, so the tests encode the author's belief rather than the source.

One pass found four bugs

A single Sol pass drove the real logic from fresh saves and found four shipped defects, every one in a family already reported complete.

The difference was lineage, not effort. On Claude-authored work here, the Anthropic review seat is now voided by default.

The pattern worth remembering. Two of the four bugs were pinned in place by tests that could never have observed the behaviour they asserted, because they stubbed the code under test. A test that cannot see what it claims to check is worse than no test — it converts a green run into evidence of the wrong thing.
