Should a move in a paused queue start it?

Up and Down in a paused or set-aside queue change the order and start nothing. A move in a running queue starts the new top entry at once.

A move starts the new top entry only when the queue is running.

A Herblore row with no herbs stays disabled, so an empty Bank cannot pick a later step even when an earlier queue entry would produce its herb. This can be part of your "not update even after you select it" note.
