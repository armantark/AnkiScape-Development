One implementation decision changed

The frozen plan remains untouched. The implementation moved the observer after reviewing the contract's undo requirement.

Plan

Write external JSONL telemetry beside the save so flag-on save bytes remain identical.

Shipped

Store telemetry in a dedicated transactional cadence_shadow namespace so review undo restores gameplay, proposal residuals, and aggregates atomically.

The flag may add instrumentation bytes. It does not change the per-review gameplay projection, XP, loot, callback sequence, dormant live cadence_profiles, or RNG state. Shadow credit can never become live cadence credit.
