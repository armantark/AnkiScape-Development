NPC Shop Frontend · Wave 4

Shop tab structure: search, shop picker, selected shop window.

This strips the colors back and focuses on the UI shape: the normal Shop tab starts with search, then shop selection, then the RuneScape-style shop panel appears below after a shop is selected.

Shape Notes

What this mock is intended to settle before Qt implementation.

1. Search firstSearch sits at the top of the Shop tab and can filter shops, item sources, services, and vendor actions.
2. Shop selection secondVisible shops appear in a compact picker under search. Locked shops can be selected for inspection; hidden reward shops do not appear.
3. Shop UI appears after selectionThe selected shop opens in the panel below, using the reference layout: Buy/Sell tabs, item grid, scrollbar, item inspector, transaction controls.
4. Backend remains authoritativeQt renders `shop_view_model_pure` fields and calls preview/apply APIs. No invented prices, stock, lock reasons, or service behavior.
