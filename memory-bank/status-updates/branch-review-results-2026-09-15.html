The one defect that is on main

Minor · main A Great Orb Project tablet sets state that nothing evaluates

When a player breaks a teleport tablet, the handler commits the state change but never runs an achievement check. The Morytania hard deed that reads runecrafting_last_teleport is therefore not evaluated while that state is live. The next review or reload credits the deed, so the loss needs a second tablet break with no review between, which is not the normal flow.

The fix already exists in the repository and is held behind a size-gate ruling on the root module. K3 claimed main had resolved this through a new event type; the verifier checked, and the event main records is consumed by no deed at all.

What the verification overturned

Refuted The diary branch reverting main

K3 rated this a blocker twice. Git settles it: the merge result is byte-identical to main. The deletions K3 saw came from a diff against a stale merge base, not from the merge.

Refuted The Ghast pouch flipping to tradeable

The claim rests on a shop row that does not exist. The pouch reads as tradeable on the merge base, on the branch, and on main alike. Nothing flips.

Refuted A wasted Fishing explosive

A zero-damage burst would only waste the lure when the cadence kernel is off. That flag defaults on and nothing outside tests writes it.

Refuted A missing save-version bump

Quest rows migrate unconditionally. The three bumps K3 cited each added a new top-level key, which this branch does not.

The digest pins hid three of their four failures

The surface test compares module fingerprints in a loop with a plain equality check, so the run stops at the first mismatch. It reported one moved pin. Four had moved. Making the pouches tradeable changes the carried and activities modules too, because those embed item data.
