NPC Shop Frontend · Wave 3

Translate the RuneScape shop window into AnkiScape Qt.

The reference layout is the right direction: a merchant title bar, Buy/Sell modes, a finite item grid, side scroll, bottom item inspector, and transaction controls. This artifact tests that shell inside the current AnkiScape menu budget without copying backend rules into the frontend.

Top chromeMerchant title, Buy/Sell/Services modes, compact search, item display controls.
GridVisible stock rows become source-backed tiles with stock, current price, and lock/temp chips.
BottomSelected item inspector plus backend preview echo and transaction quantity buttons.
SideShop picker, services/vendor actions, and a full-history button fit where the original has secondary chrome.

Qt Translation Rules
