Canonical item id per storage name

Darkan prices the exact id in your inventory; AnkiScape's flat inventory only has names, so each name needs one canonical id: the id live shop stock uses for that name (what players actually buy), else the lowest tradeable id in items.yml. The generated SHOP_PLAYER_SELL_PRICES becomes that id's exact getSellPrice. Swordfish returns to 120 everywhere (the Dungeoneering-variant 3-coin minimum disappears).

Accepted consequence (owner-directed): the anti-arbitrage clamp is removed, so Rasolo's 1-coin Poison → 825-coin sell flip comes back — but it is authentic Darkan behavior, bounded exactly the way the engine bounds it: shop stock per restock interval, and our restock clock is review-paced. The strict-arbitrage test is replaced by parity tests (uniform price across shop types, 0→1 floor, currency guard, shop-full refusal, stocked-row decay-to-default).
