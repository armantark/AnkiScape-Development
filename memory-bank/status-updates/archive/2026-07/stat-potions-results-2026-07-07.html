The engine (source-exact, reusable)

New apply_combat_stat_boost_to_pure — a boost-to-floor helper on the current-level substrate. From PotionType.kt: regular = floor(base/10)+3, super = floor(15·base/100)+5, computed off base level and capped. So a potion cures a drained stat and boosts to base+boost, but never stacks past it and never lowers a higher boost active — exactly the engine's boostCap behaviour, verified by test. The boost decays back toward base at the same 100-tick cadence the substrate already restores at.

Deliberately deferred (live-but-inert, the standard pattern): Prayer potions (need a Prayer skill), restore / super-restore potions (need the drain path to be player-reachable), and Herblore mixing to actually produce them. Until a source exists, the potions are fully wired and drinkable from whatever you own — the same state as any material-gated recipe.
