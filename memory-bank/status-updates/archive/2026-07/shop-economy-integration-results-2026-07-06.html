STAGE 3 · CONVERSIONS AT REVIEW PACE (OWNER AMENDMENT)

Tanning and sawmill moved out of the Shop tab

The four processing services became no-XP material_processing Utility activities: tan_soft_leather (Cowhide + 1gp → Leather), tan_hard_leather (+3gp), convert_logs_to_planks (Logs + 100gp), convert_oak_logs_to_oak_planks (Oak logs + 250gp) — batch 28, coins consumed per unit, same Darkan source strings, undo rides the normal review snapshot.

Decision (do not re-litigate): 2011 conversion runs were inventory-bounded at 28 unstackable items per bank run, and the review loop is AnkiScape's stand-in for that friction. An instant "Use x1000" service deletes source pacing while smelting, cooking, and soft clay already run through reviews. SHOP_SERVICES stays as an empty fail-closed contract slot; only Bartender/Benny/Karim's genuinely instant vendor actions remain as Shop-tab providers.

Also in this stage: the sell table is clamped at each name's cheapest live buy price — the flat name-keyed inventory merges item ids, so Rasolo's 1-coin "Poison" plus an 825-coin cache sellPrice on a same-named id would have minted coins (zero-profit equality stays; it's what authentic Shop.java math produces). And a latent item_registry bug died: single-output utility activities never registered because an empty outputs mapping shadowed the output_item fallback.

STAGE 4 · MOLTEN GLASS + UNLOCK AUDIT
