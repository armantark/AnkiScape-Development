Carried pack: one pack, two views

Play-test feedback exposed that the 28-slot carried pack has two disconnected UIs for the same slots — an automatic "Supply mode" summary in the Combat panel, and a manual grid on the Equipment tab that has no obvious way to fill it. The fix unifies them: the pack is auto-managed by default, and toggling Custom swaps the auto view out for the manual grid in the same spot. Plus a binary keep/drop loot pill and a real fill flow.

No Qt drag-and-drop this pass — click-to-pick is discoverable, reliable, and testable offscreen. Picker lists bank items with quantity, filtered to what you actually own.

The grid lives in both tabs

Equipment tab

  • Full pack panel: Auto | Custom switch + swappable body.
  • Sits with worn gear + combat setup, where you plan a loadout.

Bank tab

  • The same 28-slot grid, so you can arrange while looking at your bank.
  • Both grids read/write the one carried_layout; a shared refresh keeps them in lock-step, and the two switches stay synced.
Refill / Unload → one Clear
  • "Refill supplies" removed. Supplies already top up automatically at every bank run in combat (_combat_refill_context_supplies, logic_pure.py:2172), so the button was a redundant pre-load.
  • Single "Clear pack" button. Wipes the current pack back to the bank — the real need you flagged for when you switch training focus. State is still remembered per target, so switching away and back restores it.
