Edible Kebab & Beer — and the substrate potions will reuse

The visible feature is small; the reusable part is the point. You flagged that potions need the same temporary-level model, so I built it as shared infrastructure rather than a kebab hack.

The substrate (combat_current_levels)

The drain-only combat_stat_drains scaffolding — which was never actually populated — became a signed current-level model that mirrors the engine's setCurrentLevel: an absolute current level per skill, absence meaning "at base", restoring 1 toward base every 100 ticks in both directions (boosts decay down, drains recover up). Combat accuracy and max-hit are untouched when no entry exists — the parity-audited core is unchanged. Future potions (Attack/Strength/Defence pots, etc.) apply through the one shared helper apply_combat_stat_delta_pure.
