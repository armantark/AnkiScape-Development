28-Slot Carried Inventory

The number 28 already recurs everywhere — combat food cap, batch-28 utilities, the tanning "one inventory load", the Wilderness ambush's slot count. They're all shadows of one missing primitive: a real carried inventory. This makes it explicit, and gives coal/gem/rune bags a reason to exist.

1

Teeth, for everyone

A bag is worth exactly the cost of a bank run — so the limit is real, not cosmetic, or bags are inert.

2

Overlay, not replacement

The flat bank stays source of truth (protects the parity price tables + every module reading inventory[name]). The grid is a carried subset — an ordering + capacity layer.

3

Auto-execute always; swap the policy

Bank runs never open a menu. Default = a dumb-but-transparent auto-manager. Advanced = set the layout once, auto-executed. Exactly how combat auto-eat already works.

4

Advanced beats default — by a little

~10–20% fewer bank-run reviews. A nudge, never a 2x gulf that punishes casuals.

5

Input + output, unified

Processing/combat drain the grid; gathering fills it. One model everywhere — so mining coal bags and gem bags finally matter.

6

Stackable rule (source-authentic)

Stackables = 1 slot; unstackables = 1 each. A bag packs an unstackable (coal, gems) into one slot. That IS the bag's whole value.

7

Asymmetric bank cost

Gathering banks free (already one card per action). Processing/combat cost 1 review (combat keeps its existing 2). That's where the food-vs-supplies balancing lives.

8

Keep / Drop per gathering target

Keep = product to grid, free auto-bank. Drop = no product, no banking, max XP. Authentic power-mining, and the real "some you bank, some you drop."

Default vs Advanced — same machinery, different driver

Default (casual)

Just answer cards. The auto-manager packs & refills. You see "banked: 20 food / 8 coal, +1 review." Zero setup — download and play.

Advanced (opt-in)

Set the 4×7 layout & bags once. Auto-executed at every bank run. A smart pack beats the dumb default for more XP/review.

Warrants its own implementation grill before any code.
