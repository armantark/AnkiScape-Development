Second pass plan

Quest catalog moves from placeholders to authored progression.

This pass tightens the broad pre-EOC quest import around the things the playable game now needs: source-backed journals, RFD subquests, complete reward records, and a simple claim-inbox path for constrained XP lamps.

Critical

Journals are real quest content.

The current generated journal stages are generic. I am replacing that with scraped/parsed journal lines where the source exposes them, with explicit source notes when a fallback is used.
