Backend slice

Model

Add a flat save-safe quest_combat_encounter_counts map so one combat review records one enemy defeated while the old completed-encounter list remains compatibility state.

Rules

Stage blockers remain active until the completed count reaches the encounter quantity. Legacy completed flags continue to satisfy the blocker.

Generator

Parse worded combat quantities such as “Two Lava monsters” into machine-readable quantity rows through tools/build_pre_eoc_quest_catalog.py, then regenerate the catalog.

Frontend contract

Display

Existing in-progress blocker rows should show the remaining enemy quantity, not only the total source quantity.

Action

When the user resolves a combat blocker, the row remains until the last enemy in that encounter has been completed.

Config

The global combat lock stays write-once/write-everywhere: unresolved or disabled combat blocks quest advancement with player-facing wording.

Advance
