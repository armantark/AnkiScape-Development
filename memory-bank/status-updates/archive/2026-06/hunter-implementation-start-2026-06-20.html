PRE-IMPLEMENTATION PLAN

Hunter v1: Source Boundary Check

The current branch is isolated as codex/hunter-implementation. The first source pass found local 2011Scape item, NPC, shop, and spawn evidence for Hunter, but no local Hunter mechanics plugin with per-target XP tables. The implementation therefore needs one explicit source-policy decision before code lands.

Major Decision

Use archived 2011 knowledge-base tables for Hunter target XP?

Hunter differs from Mining, Woodcutting, Fishing, Cooking, Fletching, and Runecrafting because the local emulator checkout has no dedicated skills/hunter plugin table. The archived 2011 knowledge-base pages provide direct level, XP, reward, and quest note tables for the normal Hunter methods.

Recommended answer: Yes. Treat the archived 2011 knowledge-base Hunter pages as the source of record for target level, XP, and rewards, and use local 2011Scape files only to corroborate item IDs, NPC names, shops, and broad existence. Document the missing local mechanics plugin in the source audit.
Evidence

What the audit already found

Local 2011Scape checkout Has Hunter skill IDs, shops, item definitions, NPC names, and Hunter-related spawns, but no content/skills/hunter mechanics folder.
2011 archived game guide Has source tables for bird snaring, tracking, butterfly and impling netting, deadfall, box traps, rabbit snares, net traps, pitfall traps, falconry, and magical imp boxes.
Repo precedent Fletching already used pinned 2011 knowledge-base pages when the local plugin did not fully expose live historical rows.

Risk

Items to keep honest

  • Reusable Hunter tools should remain ambient like Fishing rods unless a later tool-storage design promotes them.
  • Quest-only and route-only rows should use existing lock rules only when the current generic target represents that route.
  • Jar-heavy impling and butterfly rows can be live normal rows, but missing jar sources should remain ordinary material locks.
  • Jadinkos, charm sprites, looting tables, and Puro-Puro reward exchanges are separate systems unless this pass explicitly absorbs them.
