Pre-implementation plan

Barbarians widen ordinary Combat without new engine shortcuts.

This slice promotes the 2011Scape level 8/9 Barbarian row into the enabled Combat registry. It is deliberately data-heavy and engine-light: exact source stats, simple drop tables, item icons, and tests that prove the row behaves like the existing ordinary enemies.
