Pre-Implementation Start

Combat V1 is now an implementation target, not a document cleanup.

The acceptance target is the completed grill: source-backed combat data, an undo-safe tick engine, quest handoff, a real Combat surface, assets, tests, and manual Anki verification. Partial audit rows stay out of enabled gameplay.
