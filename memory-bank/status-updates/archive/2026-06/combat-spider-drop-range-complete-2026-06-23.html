Drop Engine

The new quantity branch is deliberately narrow and only runs after a table slot wins.

  • Fixed `quantity` slots are unchanged.
  • Invalid ranges fall back to fixed quantity.
  • Tooltips render ranged quantities as `x4-6`.

Contract: { "quantity_range": (4, 6) }
