Iron Smelting RNG Landed

Smithing now models the local 2011Scape iron bar failure path without changing the deterministic behavior of the other furnace bars or forge rows.

Iron Lv 15
50%

One valid smelt consumes ore first, then rolls for the bar.

Iron Lv 45+
80%

The source curve caps at level 45 and stays there through 99.

Other bars
100%

Bronze through rune remain deterministic because the source only special-cases iron.

Behavior Matrix

Action Success Failure Telemetry
smelt_iron_bar Consumes Iron ore, adds Iron bar, awards Smithing XP. Consumes Iron ore, no bar, no XP. failure_kind = "smelt_fail"
Other smelt bars Consumes source inputs, adds the bar, awards XP. None after a valid start. Expected success is 1.0
Forge rows Consumes bars, adds forged output, awards XP. None after a valid start. Expected success is 1.0

Implementation Notes

  • apply_smithing_pure stays compatible for deterministic callers.
  • apply_smithing_action_pure lets runtime distinguish blocked actions from iron failures.
  • Ring of Forging is state-supported for future acquisition work: equipped ring gives guaranteed iron smelts and consumes 140-style charges.
  • Memory Bank source audit no longer says iron failure is unmodeled.
