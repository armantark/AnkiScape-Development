One roll means one ordinary drop.

Darkan’s executable loader does not independently roll every nonzero JSON row. It builds one cumulative selector, draws once, and returns one ordinary result. Eleven live targets now match that behavior without changing any item’s marginal probability.

Before · wrong execution model

Every sibling row rolled independently

A single kill could award several mutually exclusive ordinary drops together. Rare-item marginals looked plausible in isolation, which hid the impossible combinations.

After · executable-source parity

One cumulative ordinary selector

Each nonzero row owns an adjacent interval. One random draw selects at most one row; empty space remains an honest no-drop result. Always rows and separately invoked charms retain their own channels.
