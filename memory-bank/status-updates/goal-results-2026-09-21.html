What the game gained

  • The upkeep notes now record your resumed work on the game, with earlier history intact.
  • I can see whether remote test time went into preparation, syncing, or execution, even when a run fails.
  • Your Smithing and Summoning recipes keep a record of their source files, and a changed source cannot quietly rewrite them.
  • I can rebuild the big-picture page of which of your grilled designs are built, blocked or not started whenever you ask for it.
  • The add-on folder is much lighter: old test logs and machine output now live outside it, and every file can still be recovered exactly.
  • The list of annoyances agents hit while working on the game is down to the few that still need fixing, with every solved or explained one kept on file.
  • Helpers no longer stop work over a false alarm about the known missing item sources, and any real change to those counts still fails the check.
  • A correct reference to a test in a subfolder no longer holds back a finished landing check, and a wrong one is still caught.
  • A safety check of your real collection now refuses to report it untouched while Anki is still open and could still write to it.
  • Progress notes from before September and to-do cards finished before late August now sit whole in an archive, so a new work session has much less to read; together with the papercut list cut to its open entries, this step completes when both land.
  • The annoyances agents hit today are sorted too, so the notes a new work session reads now fit under the agreed limit.
  • A finished change no longer fails its final check just because other test runs were queued ahead of it; only slow work itself can fail it now.
  • Tidying the annoyance list no longer breaks the final check, which still insists the record explaining how it works is kept.
  • The full check of the game's windows now finishes well inside its time limit with every check still in place, so good changes stop failing just because the test machine was busy.
  • Every part of the tool that builds your achievement diaries is now simple enough to change safely, and it still makes exactly the same diaries, tasks and reward items as before.
  • The checks that catch a broken monster entry are now simpler to read and extend, and they still catch every mistake they caught before, with the same explanation.
  • The checks for one-click activity starts, changing gear or style mid-fight, and the Slayer task counter now run on every change, so a break there is caught before it reaches the game.
  • A misspelled or wrong counter name can no longer slip a diary task into the game that could never be finished; the diary builder now stops and names the task, and every diary you have today is unchanged.
  • Eighteen finished game cleanups are waiting on you: the test machine cannot click through the game on its own, so you choose how they get their hands-on check, and eight of them also still need the full automatic check before they can reach your game.
  • A test run that waits its turn now checks the game exactly as it was when the run started, so work done while it waits can no longer slip into the check or out of it.
  • One-off checks no longer quietly pick up edits made after a test run was requested, and gameplay checks still run in the regular suites.
  • A finished change that updates the final check itself is now judged by its own updated check, so correct work no longer fails because the old check expected something different, and nobody has to remember to ask for it.
  • Healthy long checks can wait their turn without another operation killing them as stale.
  • A check that guards the game's start-up code now gives the same answer in any copy of the add-on folder, so a helper working in its own copy no longer sees a false failure.
  • The tools that build your Smithing, Summoning and achievement diary data can now show on their own that a tidy-up left every recipe, familiar and diary task exactly as it was, so that check no longer relies on hand-typed commands that could give different answers for the same files.
  • Every check of the game's main window now runs once per change instead of three times, so the full automatic check finishes sooner, and a short test name picks only the checks it names.
  • The check that your Pyramid Plunder progress survives loading a save can now actually catch a mistake, and the picture tools for Big Chinchompa, the circus and Shooting Stars work again, while the broken, unused Evil Tree one is gone.
  • Eight quest steps still ask you to do something the game never lets you do, one each in Mourning's End Part I, Cold War, The Fremennik Isles, Spirits of the Elid, Enakhra's Lament, In Aid of the Myreque, The Eyes of Glouphrie and Legacy of Seergaze, because the sources for those actions are still missing; a new check now names exactly those eight and stops a quest fix from adding another such step without anyone noticing.
