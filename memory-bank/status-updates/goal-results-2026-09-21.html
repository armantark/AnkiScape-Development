What the game gained

  • The upkeep notes now record your resumed work on the game, with earlier history intact.
  • I can see whether remote test time went into preparation, syncing, or execution, even when a run fails.
  • Your Smithing and Summoning recipes keep a record of their source files, and a changed source cannot quietly rewrite them.
  • I can rebuild the big-picture page of which of your grilled designs are built, blocked or not started whenever you ask for it.
  • The add-on folder is much lighter: old test logs and machine output now live outside it, and every file can still be recovered exactly.
  • The list of annoyances agents hit while working on the game is down to the few that still need fixing, with every solved or explained one kept on file.
  • Helpers no longer stop work over a false alarm about the known missing item sources, and any real change to those counts still fails the check.
