Pre-Implementation Plan

Quest list filters without muddying start vs finish

The Quests tab needs practical filters for a 194-row catalog. The important contract is that "unable to start" means the current start lock model only; stage-aware finish blockers are a separate future model, not a hidden guess.

Quest Availability Model

Can start

Not completed, not started, and no start lock reasons.

In progress

Already started. Current AnkiScape quest reviews can continue it.

Completed

Done and reward already paid. Hideable in the new view.

Unable to start

Blocked by prerequisite quests, quest points, items, or implemented skill level checks.

Scope Boundary

This pass improves navigation and makes the current model explicit. It will not invent unsourced mid-quest blockers. If a quest can start in RuneScape but needs a later skill-gated action, that belongs in a future stage-aware quest requirement system.
