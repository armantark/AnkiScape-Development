The hazard that shapes slice 2

⚠ Coins can be stranded if the pouch goes live before the readers move

Every coin transaction today — shop buy/sell in shop_logic.py, the item-charge purchase in logic_pure.py — reads and writes inventory["Coins"]. If a migration moves coins into money_pouch before those readers are repointed, the shop looks at an empty inventory["Coins"] and the player is silently broke.

migrate Coins→pouchthenshop reads inventory["Coins"]=0→player broke
repoint readers → pouch+migrate Coins→pouch=atomic, safe

So slice 1 shipped the pouch dormant. The coins move and the CURRENT_CONFIG_VERSION bump ride with the repoint in slice 2, in one commit — never apart.
