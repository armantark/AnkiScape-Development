The headline recommendation

Define completion by end-to-end closure and mechanical archetypes, then build one narrow session substrate before Dungeoneering. Do not make “complete” mean hand-authoring every duplicate NPC in a decade-old MMO.

Cutoff correction lead

Generic random events probably do not belong

The parked seed proposes adding random events to every run, but the remaining RuneScape random events were reportedly removed on 24 October 2012—before the 20 November cutoff. Use authentic per-activity variance instead, and pin the dated update before the contract closes.

Feature trees

What was hiding off the skill list

“Complete” needs an owned place for these systems, even when the correct disposition is representative breadth or an explicit exclusion.

Must close

  • Canonical readiness graph
  • Shared search + offline Help
  • Reward currencies and shops
  • Charges, degradation, repair
  • Skill capes and 99 recognition
  • Warriors’ Guild and defenders
  • Quest promise/reference split
  • Charm-bearing bestiary breadth
  • Item acquisition and use closure

Representative breadth

  • Authentic diary tasks + rewards
  • Clue scrolls + caskets
  • Passive collections / strange rocks
  • Miniquests and Dungeoneering sagas
  • Resource dungeons
  • Quest-boss replay / Dominion Tower
  • D&D cadence families
  • Enemy/drop/context ingestion

Park or exclude

  • Persistent map + transport
  • Full multiplayer and clans
  • Legacy random events at cutoff
  • Squeal / Solomon’s commerce
  • Literal subscription-tenure simulation
  • Holiday calendars and cosmetic breadth
  • Post-cutoff substitutions
  • Visible inert previews

Release closure

  • Golden save migration fixtures
  • Export, validation, import, restore
  • Reproducible add-on packaging
  • Asset and license manifest
  • Large-save performance budgets
  • Keyboard and theme accessibility
  • Clean-profile install smoke test
  • Personal fork vs public release
