Strict Starts

Rules

A quest with missing prerequisite content is not startable. Lunar Diplomacy, Swan Song, and Legacy of Seergaze stay impossible until their prerequisite quests and unimplemented skills exist.

1 Check prerequisites

Required quest rows and required skills are validated before start.

2 Block missing systems

Unimplemented skills or quests show concise requirement text.

3 Allow only real starts

Started quests can continue; completed quests cannot restart.

Deferred XP

Storage

Rewards for implemented skills apply immediately. Rewards for planned skills are parked in flat player state and migrate once the skill becomes implemented.

✓Implemented XP uses the current skill XP key and triggers level checks.
✓Unimplemented XP lands in pending_skill_exp_rewards.
✓Migration applies pending implemented keys once and preserves future keys.
