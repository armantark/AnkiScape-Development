Achievement semantics · closure report · 2026-07-16

Progress now means what the achievement says.

Production achievements remember what the player has done. Holdings still inspect what the player owns. Decanting, spending, selling, and cross-skill XP can no longer rewrite history.

The semantic repair

Before · disposable snapshot

“Mine 1,000 coal” read the current Bank quantity. Spending coal could erase progress before completion.

→
After · durable history

Successful Mining actions add actual coal output to achievement_progress. Using the coal changes inventory, never history.

Ownership is explicit

  • Superheat output is Magic-owned, not Smithing production.
  • Construction tablets remain Construction-owned despite Magic XP.
  • Inferno-adze cuts remain Woodcutting-owned despite Firemaking XP.
  • Fishing double catches and Mining bonus ores count actual output.

Potions conserve meaning

  • Hold thresholds measure total finished doses.
  • Vials, mixes, and six-dose flasks use their real dose count.
  • Bob Barter can rearrange liquid without changing eligibility.
  • First Potion includes every finished Herblore product.

Diary gear: foundation ready, reward model open

This patch does not hand out diary gear. It removes the unstable foundation that would have made any reward system unfair. The later design grill still needs to settle a fixed progression track, player choice versus deterministic unlocks, tier upgrades, retroactive grants, and the exact item roster. It should consume sticky milestone history, never a live percentage whose denominator can move.
