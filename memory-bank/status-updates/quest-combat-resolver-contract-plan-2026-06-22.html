Pre-Implementation Plan · Combat Resolver Contract

Close the “manual encounter id” escape hatch before widening quest parity.

The catalog now has stage blockers everywhere. The next issue is combat fidelity: enabling the global resolver must not allow un-statted encounters or hand-written flags to masquerade as real battles.

Current Risk

Resolver-enabled combat is not yet a battle

The global config fails closed by default, but once enabled it only changes blocker text. There is not yet a pure path that evaluates player combat state against source-backed NPC stats and writes the completed encounter id.

3
