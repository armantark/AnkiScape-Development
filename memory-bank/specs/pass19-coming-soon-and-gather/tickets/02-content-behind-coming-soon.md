# 02: Content that needs a "Coming soon" quest locks with it

**What to build:** When a target unlock requirement names a Coming soon quest and the save does not meet it, the target's lock reason is "Coming soon". A save that already meets a quest-start or quest-stage requirement keeps the target. See spec "Content that needs a Coming soon quest".

**Blocked by:** 01 (the Coming soon set)

**Status:** not started

- [ ] Death runes show the lock "Coming soon" on a new save.
- [ ] A new save cannot start Ugthanki dung or Arctic pine cutting.
- [ ] A save that started The Feud before this change keeps Ugthanki dung.
- [ ] A target whose quest is not Coming soon keeps its own lock reason.
