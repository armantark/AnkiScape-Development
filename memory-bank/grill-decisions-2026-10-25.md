# Class rulings for questions that the period sources do not settle

Date: `2026-10-25`

Status: **owner-settled, four rulings; one refinement of ruling 3 is open.**

Each ruling settles a class of contract questions, not one item. A contract cites
the ruling and quotes its ruling line, and then it does not ask the owner a question
of that class again.

The owner started this grill on 2026-10-25 with: "All the current ankiscape
questions on the dashboard seem to be the same class of questions and I think it
would be more efficiently for you to do "frontier questioning" with me". At that
time, 7 parked items held 19 open questions. Each question had the same cause: the
period sources gave the order of events, but not the Anki review mapping or the
value. No ruling settled them, so each question scored from 5 to 9 points against
the ask threshold of 5.

The owner answered at 09:32 PDT: "1. B", "2. A", "3. A, but then we'd also have to
retroactively change all existing quests. Which I'm fine with, I'm not sure how
flattened something like Mourning's End Part 2 is in terms of time. It would be
absurdly silly for the puzzle there to be only one card", and "4. A".

## 1. Darkan stands in where the period sources are silent

Ruling line: Darkan's behavior stands in when no period source states it or
contradicts it. Each such behavior gets a placeholder marker and a register line,
so a later source find replaces it.

- When two period sources disagree with each other, the question still goes to the
  owner. The owner chose option B, which keeps those disagreements with him, over
  option A, which let Darkan pick between them.
- When a period source contradicts Darkan, the corroboration gate of
  `pre-eoc-source-verification-standard.md` still holds: the Darkan behavior is "a
  lead, not a fact".
- A period list that names the members of a set contradicts a Darkan addition to
  that set. Precedent: item 1960 keeps the Willow longbow out of Easy caskets,
  because the period Easy-only reward list names "willow shortbows" and "yew
  shortbows" and no longbow.
- Precedent: on 2026-10-25 the owner put the clue maps of items 1950, 1970, 1980
  and 1990 into Easy trails on Darkan's Easy label alone.

## 2. Values that no source gives, including Darkan

Ruling line: the contract uses the smallest value that makes the mechanic work, and
a reward never exceeds what all sources agree on. The owner gets no question.

- The value is a placeholder under the placeholder rule of
  `pre-eoc-source-verification-standard.md`, with its marker and register line.
- The smallest value must still agree with the period wording. Precedent: item 2040
  removes scent for 3 source minutes, because the period Oo'glog page says spa
  effects "wear off over the course of a few minutes", so 1 minute contradicts it.
- Precedent: item 2100 gives one sapphire total. The wiki lists a second sapphire
  for seven signs, and the independent guides do not confirm it.

## 3. One review for each quest step that changes saved state

Ruling line: one successful review for each step that changes saved state: an item
gained or spent, a door opened, a stage passed. A step that is only dialogue joins
the next such step. A world action outside a quest, such as the Oo'glog mud bath,
also costs one review.

- The owner accepts that existing quests change to this rule: "then we'd also have
  to retroactively change all existing quests. Which I'm fine with".
- **Open refinement:** a long step, such as a puzzle, is more than one card. The
  owner: "It would be absurdly silly for the puzzle there to be only one card",
  about Mourning's End Part 2. The rule for the review cost of a long step is not
  settled yet. Until it is, a contract that holds a long puzzle asks the owner.

## 4. Text-only changes inside an existing panel

Ruling line: a change that only replaces text or numbers inside an existing panel
needs no owner question when it adds no control, changes no layout, and adds no
screen.

- The frontend-taste review still runs before promotion.
- New controls, layout changes and new screens still go to the owner.
- Example: item 2050 replaces the Duel Arena exchange score and its five-review
  limit with both fighters' life points, the review count and the outcome.

## Wording in owner questions

An owner question names the November 2012 restoration "Darkan", the glossary term.
On 2026-10-25 the open questions used three names for it: "later Darkan
reconstruction", "retained reconstruction" and "modern reconstruction".
