## Blockers to pin in the contract before implementation

Each item below is behavior the current source has and the written contract does not state. Each one can change behavior if an implementer "cleans" it.

1. **Lifepoint default asymmetry.** Line 1255 reads `data.get("combat_lifepoints", max_lp_for_dream)`. Lines 1264 and 1265 read `data.get("combat_lifepoints", 0)`. The defaults differ on purpose in effect: a missing key is ineligible at the check and heals from 0 at the transaction. The helper must keep the `0` default. It must not reuse `max_lp_for_dream` as the default.
2. **Raw rune debit.** Line 1259 tests affordability through `_non_negative_int(inventory.get(rune, 0), 0)`. Line 1262 debits through the raw subscript `inventory[rune] -= amount`. A zero-amount cost entry for an absent rune passes the test and then raises `KeyError`. A non-integer stored count raises `TypeError`. The helper must keep the raw subscript and must not add a `.get(rune, 0)` guard.
3. **Result object identity.** Line 1267 builds one dict. Line 1268 stores that same object in `data["combat_last_result"]`. Line 1269 returns that same object as the third tuple element. The stored value and the returned value are one object, not two equal dicts. The contract must state that the caller stores the helper's returned object directly. A defensive copy at either side changes observable aliasing.
4. **No inventory write on the unaffordable path.** Line 1258 normalizes a falsy or non-Mapping inventory to `{}` in a local only. When the runes are short, `data["inventory"]` stays untouched, including when it holds `None`. The helper must not write the normalized local on the `None` return.
5. **In-place mutation of `data`.** The helper signature returns `result | None`, so the contract must say the helper mutates the caller's `data` mapping in place and returns no new mapping. Otherwise an implementer can copy `data` inside the helper and strand the writes.
6. **Iteration order.** Both `dream_cost.items()` loops must keep the caller-supplied mapping order, and `runes_used` must stay `dict(dream_cost)`, a copy.
