# Hunter 2011Scape Source Audit - 2026-06-20

## Scope

Hunter v1 is implemented as a review-action Gathering skill with source-backed
target rows, item outputs, storage defaults, achievements, assets, quest locks,
runtime reward handling, and a grouped Skills-hub target tree.

The local 2011Scape cache/snapshot was not missing Hunter item/NPC/object
identity. It has the item names and ids needed for player-facing storage and
icons. What is missing in the local 2011Scape rev-667 checkout is a Hunter skill
mechanics plugin. For that reason this pass uses:

- 2011.rs Hunter guide pages for player-facing level, XP, method, and location rows.
- Local 2011Scape cache item names/ids for canonical inventory storage keys.
- Local 2012scape/Darkan Hunter code only as factual mechanics parity evidence
  for item/NPC ids and action families.

## Implemented Rows

- Bird snaring: crimson swift, golden warbler, copper longtail, cerulean twitch,
  tropical wagtail, and wimpy bird.
- Butterfly netting: ruby harvest, sapphire glacialis, snowy knight, and black
  warlock. These use deterministic jar consumption because the 2011 guide gives
  the row data but the Darkan source does not implement butterfly netting.
- Deadfall: wild kebbit, barb-tailed kebbit, prickly kebbit, and sabre-toothed
  kebbit, consuming `Logs` on successful catch.
- Box trapping: ferret, chinchompa, red chinchompa, pawya, and grenwall.
- Net trapping: swamp lizard, orange salamander, red salamander, and black
  salamander.
- Falconry: spotted kebbit, dark kebbit, and dashing kebbit.
- Magic boxes: catch imp with magic box, consuming `Magic box` and producing
  `Imp-in-a-box (2)`.
- Implings: all 14 2011/pre-EOC implings as both Puro-Puro and world rows,
  consuming `Impling jar` and using the guide's separate XP values.

## Quest And Route Decisions

- `catch_ferret` is gated by Eagles' Peak.
- `catch_wimpy_bird` is gated by As a First Resort because the current generic
  target represents the Oo'glog route.
- `catch_pirate_impling_puro_puro` and `catch_pirate_impling_world` are gated
  by Rocking Out.
- `catch_swamp_lizard` is gated by Priest in Peril as the current Morytania
  net-trapping route precedent.
- Pawya and grenwall record Regicide-start route access in notes, but do not get
  a completion gate. The current quest-lock model supports completion and
  ability unlocks, not partial-route access.

## Reusable Tools And Supply Bridge

- Hunter target specs now separate reusable `tools` from consumed
  `requirements`. The runtime checks tools as bank/inventory gates but does not
  delete them on success.
- Bird snaring requires `Bird snare`; box trapping requires `Box trap`;
  butterfly netting and Puro-Puro implings require `Butterfly net`; net trapping
  requires `Small fishing net` and `Rope`. World implings remain jar-gated
  without a reusable-net gate in this v1 model.
- `Butterfly jar`, `Impling jar`, `Magic box`, and `Logs` remain consumed
  requirements and are only deleted on successful catches.
- `Buy Hunter supplies` is a temporary one-shot Utility/Activities bridge, not a
  final shop interface. It spends `500 Coins`, grants a starter/restock bundle
  of source-backed Hunter supplies, and switches AnkiScape off after one review
  so the review action multiplier cannot repeat the purchase.
- Bundle stock sources are Darkan `Aleck's Hunter Emporium` for Hunter tools,
  butterfly jars, and magic boxes; `Elnock's Backup Supply` for impling jars;
  `Lumbridge Fishing Supplies` for small fishing nets; and `Shantay Pass Shop`
  for rope. The exact per-item shop economy is deferred with the broader
  shop/GE UX; `500 Coins` is an AnkiScape bridge price chosen for the current
  quest-reward coin scale.

## Deferred Rows

- Tracking trails, pitfall trapping, rabbit snaring, barehand butterfly/impling
  catches, and Herblore Habitat/Jadinkos remain deferred. They need action-state,
  route/location, Agility, or broader post-2011 systems that are larger than
  Hunter v1.
- Grenwall herb drops are deferred; v1 awards the guaranteed minimum 18
  `Grenwall spikes` plus `Bones`.
