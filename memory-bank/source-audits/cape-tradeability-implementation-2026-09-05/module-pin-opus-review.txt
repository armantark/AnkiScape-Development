## Limitations that stay open

2. Native acceptance has not run.
3. The two catalog rows reach a pin only through `ROOT_QT_DIGEST`, because the plain surface has no `__init__.py` payload. A plain-only gate does not protect them.
4. The proof gives complete bytes for the catalog rows but only scope strings for the four metadata field edits. The reversal test bounds that delta to the named fields; it does not disclose the new values. Pin correctness does not depend on the values, so this is a disclosure gap, not a defect.
5. The before hashes come from the driver raw baseline `6438d422`, through a path-scoped equality claim, not from a direct capture at `cd6747a6`.

7. The packet does not quote the literals that the pin file holds today. Whoever applies the edit must confirm each `before` string in `tests/test_module_surface.py` at edit time; a mismatch means the pin drifted, not that the measurement is wrong.
